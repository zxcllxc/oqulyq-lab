# Oqulyq Lab — Data-Driven Curriculum

EdTech Hackathon by Zhambyl Hub, кейс 1. Платформа для методистов: решения об учебниках и учебных часах по измеримым результатам учеников.

**Демо:** https://oqulyq-lab.vercel.app (данные синтетические, школы вымышленные)

## Что делает
1. **Трудные темы** — средний балл и доля усвоивших (≥60) по каждой теме, цель 70%.
2. **Честное сравнение учебников** — сравниваем классы, а не учеников; убираем уровень класса на входе (итог прошлого года). Эффект = факт − ожидание, 95% доверительный интервал. Если интервал задевает 0 — «разница не доказана», меньше 3 классов — «мало данных».
3. **Диагноз причины** — если тема проседает во всех учебниках, не хватает часов; если только в одном — проблема главы учебника.
4. **Перераспределение часов** — общий объём неизменен; часы получают темы с дефицитом (по очереди, начиная с наибольшего отставания), отдают темы, где цель достигнута (не ниже 75% плана). У каждой строки — объяснение «почему».
5. **Импорт CSV/Excel** методиста, шаблон скачивается в приложении. Русский и казахский.

## Формат данных
`school, class, textbook, topic, score (0–100), baseline (0–100), hours (опц.)` — одна строка = один ученик × одна тема.

## Код
- `src/lib/analytics.ts` — все расчёты (прозрачные, без «чёрного ящика»)
- `src/lib/data.ts` — генератор демо-данных (seed 2026)
- `src/app/page.tsx` — интерфейс

```bash
npm install && npm run dev
```

Стек: Next.js 15, TypeScript, Tailwind CSS 4, SheetJS. Расчёты идут в браузере — данные учеников не покидают компьютер методиста.
