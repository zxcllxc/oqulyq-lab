# Методика Oqulyq Lab

Все расчёты в `src/lib/analytics.ts`, тесты в `tests/analytics.test.ts` (`npm test`).

## 1. Трудные темы
- Средний балл темы = среднее по всем результатам учеников.
- Усвоение = доля учеников с баллом ≥ 60 (`PASS`).
- Трудная тема: средний балл < 70 − 5 (`TARGET` = 70).

## 2. Честное сравнение учебников
- Единица анализа — класс (средний балл класса по теме). Большая школа не перевешивает маленькую.
- Ожидаемый балл класса по теме: `a(тема) + b · baseline`, где baseline — итог класса за прошлый год. `b` — общий наклон МНК внутри тем, `a` — свой для каждой темы.
- Остаток = факт − ожидание. Эффект учебника = средний остаток его классов.
- 95% ДИ = эффект ± 1,96 · σ / √k (k — число классов).
- Вердикт: ДИ целиком выше 0 — «выше ожидаемого», целиком ниже — «ниже ожидаемого», задевает 0 — «разница не доказана», k < 3 — «мало данных».
- Ограничение: один фактор (уровень на входе); нормальная аппроксимация вместо t-распределения при малых k.

## 3. Причина просадки
- Тема ниже цели и есть учебник с «ниже ожидаемого», эффект которого ≤ −(разрыв/2) → проблема главы, часы не добавляем.
- Иначе → дефицит часов.

## 4. Перераспределение часов
- Годовой объём фиксирован.
- Потребность темы с дефицитом: 1 ч за каждые 7 п.п. разрыва, от 1 до 3 ч.
- Доноры — темы, где цель достигнута; каждая отдаёт не больше, чем оставляет ≥ 75% плана.
- Часы раздаются по кругу: сначала по 1 ч каждой теме по убыванию разрыва, потом вторые часы и т. д., пока есть резерв.
- «Что если»: прогноз +2,5 п.п. за час — демо-допущение (в интерфейсе подписано).
