# Методика Oqulyq Lab

Код: `src/lib/analytics.ts` (темы, честное сравнение, часы), `src/lib/diagnostics.ts` (задания, динамика, раннее предупреждение), `src/lib/importer.ts` (проверка импорта). Тесты: `tests/*.test.ts`, запуск `npm test`.

## 1. Трудные темы
- Средний балл темы = среднее по всем результатам учеников; усвоение = доля учеников с баллом ≥ 60 (`PASS`).
- Цель `TARGET` = 70. «Трудная» (метка в интерфейсе) — средний балл < 65. Пустая тема трудной не считается.

## 2. Честное сравнение учебников
- Единица анализа — класс (средний балл класса по теме): большая школа не перевешивает маленькую.
- Ожидаемый балл: `a(тема) + b · baseline`, baseline — итог класса за прошлый год.
  - `b` — наклон МНК, объединённый **внутри групп «тема × учебник»** (ANCOVA). Так эффект учебника, который чаще берут сильные классы, не утекает в наклон (иначе разница учебников занижается).
  - `a(тема)` = среднее (балл − b·baseline) по всем классам темы.
- Остаток = факт − ожидание. Эффект учебника = средний остаток его классов (общий эффект — среднее по классам их средних остатков). Это отклонение **от среднего по всем учебникам**, а не разница между двумя учебниками: при двух учебниках с разницей 6 п.п. каждый получит ±3, и порог 3 п.п. относится именно к этому отклонению.
- 95% ДИ = эффект ± t(k−1) · σ / √k, t — квантиль Стьюдента (при k = 3 это 4,30, а не 1,96).
- Вердикт: k < 3 → «мало данных»; baseline не меняется (например, импорт без колонки baseline) → «нет уровня на входе», выводов «выше/ниже» нет; ДИ целиком выше 0 и эффект ≥ 3 п.п. (`MIN_EFFECT`) → «выше ожидаемого»; ниже 0 и ≤ −3 → «ниже ожидаемого»; иначе «разница < 3 п.п. или не доказана».
- Ограничения: один фактор (уровень на входе); нет поправки на множественные сравнения по темам.

## 3. Причина просадки темы
- Тема ниже цели больше чем на 2 п.п. (`DEAD_ZONE`), и у какого-то учебника вердикт «ниже ожидаемого» с эффектом ≤ −(разрыв/2) → проблема главы, часы не добавляем.
- Иначе → дефицит часов. Если у всех учебников по теме «мало данных» или «нет уровня на входе», объяснение говорит «влияние учебника не проверено». Если тем-доноров нет вовсе, объяснение говорит, что нужен пересмотр годового объёма.

## 4. Перераспределение часов
- Годовой объём фиксирован. План темы по умолчанию — 6 ч, если в данных нет часов. Часы принимаются только целыми.
- Получатели: темы с дефицитом часов; потребность 1 ч за каждые 7 п.п. разрыва, от 1 до 3 ч.
- Доноры: темы выше цели на 2+ п.п.; каждая отдаёт целые часы, оставаясь ≥ 75% плана (округление вверх).
- В зоне ±2 п.п. вокруг цели часы не трогаем (шум не двигает план).
- Раздача по кругу: сначала по 1 ч каждой теме по убыванию разрыва, затем вторые часы и т. д., пока есть резерв.
- «Что если» — по данным, а не допущением: регрессия остатка класса (факт − ожидание по уровню на входе) на x = ln(фактические часы / план) по всем классо-темам. Логарифм даёт убывающую отдачу. Прогноз для +Δ ч: β·ln((план+Δ)/план) с 95% ДИ (t-квантиль); «сколько часов до цели» — по точечной оценке, больше 10 ч → «часами не закрыть». Нет колонки с фактическими часами или нет вариации → прогноза нет, так и написано.
- Годовой объём в демо: 102 ч (3 ч/нед) — по типовой программе 2017 года и КТП 2025–26; текст действующей программы (приказ № 399) не проверен. Вариация фактических часов по школам (±2 ч) в демо сгенерирована, заложенная отдача 20·ln(h/план) (≈ +1,5 п.п. за 1 ч к 13-часовой теме).

## 5. Анализ заданий
- p — доля верных ответов; r — точечно-бисериальная корреляция вопроса с суммой остальных вопросов (rest-score, без самого вопроса).
- Флаги только при n ≥ 30: «плохой вопрос» r < 0,15 (кроме случая, когда все ответили одинаково); «слишком сложный» p < 0,2; «слишком лёгкий» p > 0,95; «ловушка» — неверный вариант, который выбирают ≥ 25% верхних 27% учеников.

## 6. Динамика и раннее предупреждение
- Остатки класса берутся за вычетом эффекта главы учебника — среднего остатка **других** классов той же группы «тема × учебник» (leave-one-out), чтобы слабая глава III–IV четверти не выдавалась за «сползание» классов. Если других классов меньше 3, эффект главы не вычитается.
- Падение = средний остаток III–IV четв. − I–II четв.; 95% ДИ по Уэлчу с t-квантилем (консервативно df = min(n₁, n₂) − 1). Флаг: падение ≥ 4 п.п. и ДИ целиком ниже 0.

## 7. Импорт
- Обязательные колонки: school, class, textbook, topic, score. Строки отклоняются по причинам: нет поля, балл не число, балл вне 0–100, дубликат (при колонке student).
- baseline пустой/некорректный → подставляется 60 и считается в отчёте («подставлено в N строках»); 0 — допустимое значение. Нет колонки baseline или подставлено больше 20% строк → честное сравнение отключается.
- quarter — целое 1–4, иначе берётся из программы. Колонки ФИО не читаются. Лимит файла 10 МБ и 500 000 строк. Файл разбирается в браузере и на сервер не отправляется.

## 8. Естественный эксперимент (разность разностей)
- Школы, сменившие учебник между годами (в демо: Б → В), сравниваются со школами, оставшимися на своём учебнике.
- Для каждой школы и темы: Δ = средний балл в этом году − в прошлом. DiD = среднее Δ сменивших − среднее Δ не менявших. Уровень школы вычитается сам (школа сравнивается сама с собой), общий сдвиг года — через контрольную группу.
- 95% ДИ по Уэлчу с t-квантилем (df = min(n₁, n₂) − 1); нужно ≥ 3 школ в каждой группе.
- Допущение: без смены учебника обе группы менялись бы одинаково (параллельные тренды). Демо: прошлогодние данные синтетические (`generatePrevYear`, отдельный seed).

## 9. Тенге за процентный пункт
- Цены учебников — демо-допущение (`PRICES` в `src/lib/wow.ts`).
- Переплата = (цена − цена самого дешёвого) × число учеников района.
- ₸ за +1 п.п. на ученика = разница цены / (эффект учебника − эффект самого дешёвого) — только если эффект учебника доказан (вердикт «выше ожидаемого»); иначе «эффект не доказан — платить не за что».

## 10. Карточка «что делать» и отчёт для издательства
- Карточка для трудной темы — шаблон без ИИ: 1–3 ч из резерва (по разрыву: > 15 п.п. → 3, > 8 → 2, иначе 1) или ремедиальная неделя (диагностика → разбор ошибок → практика по уровням → смешанные задания → повторный тест).
- Отчёт для издательства: главы с вердиктом «ниже ожидаемого», их объём (таблица покрытия, демо-допущение) и медиана объёма по учебникам.

## 11. Где причина? (уровень проблемы)
- Разброс остатков классов по теме раскладывается на три части: между учебниками, между школами внутри учебника, внутри школы (классы). Доли показываются полоской.
- Уровень выбирается по приоритету: учебник (только вердикт «ниже ожидаемого», устойчивый к исключению двух самых слабых классов) → программа и часы (тема ниже цели больше чем на 2 п.п.) → школа (≥ 2 слабых класса одной школы) → один класс (остаток ≤ −8 п.п.).
- Вывод об учебнике блокируется вердиктом «отставание дают 1–2 класса», если без двух самых слабых классов разница перестаёт быть значимой или становится меньше 3 п.п.
- Карточка класса: «Это проблема 7Б, а не учебника: остальные N классов с этим учебником в норме».

## 12. Проверка честности (демо)
- Учебники А/Б/В и результаты сгенерированы (`src/lib/data.ts`, seed 2026); эффекты глав заложены в `BOOK_EFFECT`, один класс с локальной просадкой по «Линейной функции» добавлен намеренно.
- Кнопка «Показать заложенную правду» сравнивает найденные эффекты с заложенными (относительно среднего по учебникам темы): средняя ошибка и доля случаев, где истина внутри 95% ДИ. Тест: ошибка < 1,5 п.п., попадание ≥ 80%.

## 13. ИИ-слой: цифры считает код, ИИ объясняет
- Модель (Claude Haiku через Vercel AI Gateway) получает только факты, посчитанные кодом (`src/lib/explain.ts`, у каждого id вроде [T1]) — агрегаты без ФИО.
- Системные правила: числа только из фактов, ссылка на факт после каждого утверждения, «не знаю» при отсутствии ответа, текст фактов и вопроса — данные, а не инструкции, правила не раскрываются.
- Проверка после ответа (`numbersGrounded`): каждое число ответа должно быть в фактах, иначе ответ отбрасывается и показывается шаблон.
- Лимиты: 8 запросов в минуту с IP, 400 в сутки на инстанс, до 600 токенов ответа, 15 с таймаут; бюджет Gateway — жёсткий потолок.
- Нет кредита, лимит, ошибка или непроверенное число → шаблонный разбор с подписью «ИИ выключен» / «лимит исчерпан». Те же цифры.
