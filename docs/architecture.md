# Архитектура и рост до страны

## Сейчас (демо)
```
Браузер ── page.tsx ── analytics.ts (чистые функции: темы, честное сравнение, часы)
              │
              └─ /api/v1/* (Next.js route handlers) ── PGlite (Postgres в WASM, db/schema.sql) ── сгенерированные демо-данные
```
- Одно ядро расчётов `src/lib/analytics.ts` для браузера и сервера.
- Импорт CSV/XLSX методиста считается в браузере: файл не уходит на сервер.

## Прод (пилот → область → страна)
```
Методист ── Next.js (Vercel, регион fra1/ближайший) ── API /api/v1 (OpenAPI)
                                                    ├── Postgres (Neon → сервер в РК по закону о ПД)
                                                    │     ├── таблицы db/schema.sql
                                                    │     └── materialized view class_topic_stats (обновляется после импорта)
                                                    └── очередь импорта (большие файлы, проверка качества)
```

## Почему выдержит масштаб
- Объём: 8 048 школ ([stat.gov.kz](https://stat.gov.kz/ru/news/bolee-8-tysyach-shkol-kazakhstana-nachali-novyy-uchebnyy-god/)), ~3,9 млн учеников. Оценка: 3,9 млн × ~10 тем-тестов × 6 предметов-с-аналитикой ≈ 230 млн строк `result` в год. Это обычный масштаб для Postgres с партиционированием `result` по году (и при необходимости по региону).
- Дашборды не читают сырые результаты: они читают `class_topic_stats` (класс × тема × четверть, ~тысячи раз меньше строк). Честное сравнение считается по классам, а не по ученикам, поэтому даже на уровне страны это десятки тысяч точек на тему.
- Индексы: `(district_id, topic_id, quarter)` и `(textbook_id, topic_id)` покрывают фильтры дашборда; `result(student_id)` — карточку ученика.
- Кеш: агрегаты по области/району кешируются на CDN (данные меняются раз в четверть).
- Роли (`app_user.role` + `scope_id`) режут выборку на уровне SQL: методист школы видит свою школу, района — район, области — область.

## Персональные данные
- Ученик хранится как `pseudo_id` (хэш с солью), без ФИО.
- Хранение в РК для прод-версии (Закон РК «О персональных данных и их защите»), до пилота — только обезличенные демо-данные.
